## Публикация изменений разработчиком

```sh
npm run publish:expo -- --message "Описание обновления"
```

Команда собирает и загружает JS-бандлы и ассеты iOS/Android в Expo Update. На iPhone не нужно запускать эту команду перед каждым открытием: она нужна только разработчику для публикации новой версии. Секреты Expo не хранятся в репозитории; CLI использует локальную авторизацию.

`expo-updates` установлен через `expo install`, в версии для SDK 58; библиотека входит в Expo Go. `app.json` привязан к Expo project ID и update URL; `eas.json` содержит каналы для профилей сборки. Платные/нативные сборки и TestFlight не запускались. Интерфейс, токены и продуктовая логика не менялись.
