# Синхронизация токенов с Box UI

Источник: соседний `../box-ui`, `tokens/figma/*.txt`; Box UI используется только для чтения. Снимок графа без коллекции иконок: `tools/tokens/box-ui.snapshot.json`. В нём записаны revision исходников и SHA-256 содержимого выгрузок, включая незакоммиченные изменения. В проект не добавлены зависимости или нативные модули.

- `npm run tokens:sync` — прочитать актуальный Box UI, обновить снимок, `src/theme/box-ui.generated.ts` и реестр использований.
- `npm run tokens:check-source` — проверить снимок против актуального Box UI, ничего не записывать.
- `npm run tokens:check` — автономная проверка генерации и реестра по сохранённому снимку, в том числе в CI без соседнего репозитория.
- `npm test` — включает автономную проверку и проверку сохранения исходных значений.

Для другого расположения источника: `node tools/tokens/sync.mjs --check --source <путь-к-box-ui>`. Не запускайте сборку Box UI: парсер читает исходные выгрузки напрямую. Экспортированные CSS `var()` не подходят React Native, поэтому генератор разрешает ссылки в числа и строки.

Семантическая привязка: `colors.card` → `sys-theme:surface/base/fill/raised`, Light. Белый/чёрный → ахроматические примитивы `sys-color`. Остальные цвета не приравниваются к случайно совпавшей ступени палитры. Размеры, spacing, радиусы, кегли, веса и интерлиньяж используют соответствующие примитивные шкалы. Числа геометрии не объявляются семантическими ролями `m/l/xl` без подтверждения макетом.

В приложении сохраняется существующая светлая тема. Переключение на Dark, Inter или другую акцентную моду не добавляется: это изменило бы дизайн. Все моды и транзитивные ссылки сохранены в снимке; генератор проверяет существование ссылок и циклы для каждой моды каждой коллекции. Разрешение `alpha()` остаётся в графе; альфа Box UI не подменяет локальные материалы.

Локальные исключения: `src/theme/tokens.ts`, системные семейства и типографика в `typography.tsx`, точные измерения HTML-макетов в стилях компонентов. Полный реестр с файлом, строкой и значением: `docs/audits/token-inventory.json`. Нестандартные интервалы (например 3, 7, 11), размеры иллюстраций, координаты/проценты, толщины линий и материалы сохраняются. В Box UI нет отдельной шкалы толщин обводок, теней, времени анимаций и blur; `prim-size` не используется для выдуманной семантики таких значений. Иконки и встроенная графика исключены.

При обновлении сначала просмотрите diff снимка и отчёт конфликтов. Выполните все проверки и визуальную проверку: `tokens:sync` может обновить значение привязанного токена. Проверка `tools/tokens/check-values.mjs` раскрывает новые обращения к токенам и сравнивает AST всех исходных файлов с базой `b4910ef` (без комментариев, форматирования и новых импортов; порядок импортов нормализован). Она ловит изменение цвета/числа или поведения при этой миграции; это не доказательство рендеринга на устройстве. База не обновляется автоматически синхронизацией. После будущего согласованного изменения дизайна/функций её нужно явно пересоздать от соответствующего проверенного коммита: `node tools/tokens/check-values.mjs --record <коммит>`. Не пересоздавайте базу для обхода ошибки текущей миграции.
