# Фон, прокрутка и закрытие редакторов

По замечанию пользователя исправлены четыре связанных дефекта.

1. В темах старых редакторов оставались непрозрачные серые backdrop. Теперь это rgba(0,0,0,.2), настоящий родитель с небом остаётся виден. Проверены входы с Главной через меню в лимит запусков, лимит времени и рутину; в sky-pixels.json зафиксирован синий цвет верхней области всех трёх кадров.
2. Жест, начавшийся при scrollTop>0, закрепляется за прокруткой до отпускания пальца. Даже достижение начала списка в этом же жесте не разрешает закрытие. Выявлен порядок responder/touchStart: повторный reset стирал исходную позицию. Теперь состояние привязано к timestamp одного touch. В Chrome воспроизведены scrollTop237 и тяга300pt: лист остаётся на месте; новый жест из scrollTop0 закрывает его. Для iOS pageSheet NativeScrollGate запрещает dismiss при прокрутке и не включает его до окончания текущего жеста; lifecycle-тест проверяет блокировку callback и повторное разрешение после250ms.
3. Общий SheetScrollView по умолчанию без bounces/alwaysBounceVertical и Android overscroll, чтобы не оголять край поверхности. На Главной градиент связывает небо с точным цветом фона внизу; собственный фон scroll-content и подложка при верхнем pull предотвращают резкое появление серого.
4. Отмена, фон и подтверждения старых листов переведены на close(afterClose): длительность, strict/method, приложения, привычки, галерея/детали, оценка времени и меню Блокировать. Центрированное подтверждение strict теперь fade через SheetModal motion=dialog. Корневые редакторы закрываются240ms также перед созданием правила/сохранением шаблона; данные и навигация применяются после выхода. Выбор без подтверждения не сохраняется.

В contact.jpg: Главная, три редактора с настоящим небом, три промежуточных закрытия и два жеста списка. Кадры просмотрены в Chrome393×852. У каждого редактора проверено, что он ещё смонтирован через80ms после закрытия фоном и снят после анимации. Функциональные проверки session-flow/time-limit/routine/lock-rule, reflection/gallery; typecheck/lint/web-export/iOS JSbundle и modal-lifecycle. Физический iPhone/Android визуально не проверены; нативная блокировка свайпа подтверждена тестом iOS-ветки и сборкой, не жестом на устройстве. Новых экранов0.
