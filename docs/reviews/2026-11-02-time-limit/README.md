# Лимит времени — 2 ноября 2026

Перенесены114–127.128/130 обновлены в части созданного лимита на существующей странице «Правила»; вся страница не является копией исходного кадра.129 (инструкция по общему доступу Screen Time между устройствами) пока не перенесён.

## Что работает

- Маршрут `/limit`, пункт «Лимит времени» меню. Заголовок редактируется, рекомендации задают10/15/30минут.
- Выбор нескольких приложений и целых категорий. Общий AppCatalog используется также в выборе одного приложения для лимита запусков. Черновик хранит приложения и категории отдельно; закрытие отменяет изменения, галочка подтверждает. Без выбора Расписание/Новый шаблон недоступны.
- «После»: порог1минута–24часа в общем UnlockDuration. На24часах минуты только00. Подтверждение сохраняет, закрытие отменяет. «Для чего: Выбранные» и «Заблокировать до: Завтра» пока фиксированы, их меню в исходном наборе не показаны.
- «Активно»: семь дней недели, нельзя выключить последний день. Порядок дней сохраняется.
- «Ещё открытия»: общий SessionUnlocks, число/длительность/способ открытия и отмена через существующие листы. Название ожидания в этом контексте соответствует исходнику. Системный Switch на iOS сохранён.
- «Уведомления»: порог до достижения и интервал, шаг10минут, уменьшение до0/«Нет». Значения ограничены текущим лимитом и уменьшаются при уменьшении лимита. Это сохранение конфигурации, не планирование системных уведомлений.
- Сохранение лимита и шаблона. AppState хранит createdLimits и savedLimitTemplates; SavedTemplateCard общий для сессий/лимитов. Применение шаблона создаёт отдельную запись. Активный счётчик таббара/заголовка обновляется; после добавления показывается новая карточка, после создания шаблона — раздел шаблонов. Смена демо-сценария очищает новые записи.

## Проверка

`tools/check-time-limit.mjs`: запрет пустого сохранения, отмена/сохранение категории, порог2ч15мин, граница24ч и отмена порога, дни недели, дополнительные открытия,10минут до лимита, создание правила, активный счётчик, создание/применение шаблона, поиск без учёта регистра. Панель уведомлений x36/y480/w321/h27 проверяется автоматически. Ошибок браузера нет.

Регрессия общих компонентов: check-lock-rule, check-session-unlocks, check-session-icons. Typecheck, lint, web-export, iOS bundle. Сопоставлены16состояний в Chrome393×852; пары comparison-* в общей галерее, контактные листы contact-* для навигации. Крупные пары используются для проверки размеров. На физическом iPhone/с системной клавиатурой и VoiceOver пакет визуально не проверен.

## Ограничения

Настоящего FamilyControls/Screen Time, подсчёта экранного времени, блокировки, синхронизации между устройствами и уведомлений ОС нет. Каталог локальный:15демо-приложений и10названий категорий. Счётчик категорий обозначает выбранные категории, не реальное количество установленных приложений. Данные хранятся в памяти.129 остаётся в очереди.128/130 используют фактические соседние данные приложения и общий компонент уведомления, отличаются от исходной полной страницы. Полная приёмка всего проекта1:1 не заявлена.

## Где посмотреть

Начать блокировку → Лимит времени → Блокировать → галочка у «Социальные сети» → сохранить. Далее доступны После, Активно, Ещё открытия и Уведомления. Кнопка «Расписание» добавляет лимит в Правила.
