# Закрытие вложенных листов свайпом

SheetGrabber общий для22мест использования в контейнерах и редакторах. Видимая ручка сохраняет размеры/цвет из макета, зона жеста40pt на всю ширину верхнего края. Перетаскивание двигает только sheet-content; затемнение, overlay и родитель не перемещаются. Порог72pt либо скорость>.65 при пути>18pt. Короткий жест возвращает лист пружиной. Свайп закрывает черновик через cancel владельца, не через save; на iOS действие ждёт onDismiss. Нажатия за пределами листа сохранены. При открытом локальном меню BlockScreens/RuleDetails жест выключен; центрированные GlassDialog не перетаскиваются.

Охват: SettingsStack/PlainSettingsSheet (и все их потребители), напоминания, форма занятия, переименование группы, группы/параметры/иконки, способы/длительность/strict, выбор приложений/привычек и форма привычки, галерея/детали, открытие приложения, четыре редактора правил. Удалены5движущихся фальшивых задних листов: HabitForm/HabitPicker/UnlockMethodSheet/SingleAppPicker/LimitAppPicker. Корневые редакторы используют onHidden для возврата маршрута после анимации.

В Chrome393×852 проверены10жестов: короткий возврат; закрытие цели, напоминаний, времени, групп, настроек правил; четыре корневых редактора. Измерены следование за пальцем, неподвижные parent/backdrop, сохранение нижнего листа и число снятых окон. Кадры drag-N и checks.json. Регрессии profile-sheet-motion (7входов/выходов), session-flow, modal-lifecycle, typecheck/lint, web-export и iOS JSbundle проходят. Скриншот drag-1 и контактный лист всех10жестов просмотрены. Остальные подключённые поверхности проверены по коду, отдельного ручного жеста для каждой пока нет. На физическом iPhone/Android не проверено.
