# Подтверждения: неподвижная подложка и последовательное закрытие

GlassDialog переведён на тот же SheetModal с отдельным типом motion=dialog: центрированное окно плавно проявляется/гаснет, без выезда снизу. Затемнение не меняет положение. Существующее появление PopIn и вся геометрия/блюр сохранены. Отмена и подтверждение выполняются после исчезновения диалога и нативного onDismiss на iOS.

Проверены два появления и два закрытия БЕТА напоминаний. По кадрам проверены отсутствие transform у подложки/контейнера диалога, полная высота 852, промежуточная прозрачность; нижний лист остаётся неподвижным, пока диалог существует. Отмена сохраняет черновик; подтверждение затем запускает закрытие нижнего листа и сохраняет настройки. Повторно проверены диалоги удаления экрана/шаблона и обновления лимита. Физический iPhone визуально не проверен.
