# Регрессии закрытия модальных окон

Браузерная проверка трёх редакторов: синий фон родителя сохраняется, выход анимируется, жест возврата прокрученного контента не закрывает окно. Подробности в checks.json и снимках рядом.

Отдельная проверка tools/check-modal-lifecycle.mjs воспроизводит вызов старого iOS onRequestClose после запрета dismiss без промежуточного rerender. Предыдущий исходник падает, исправленный проходит. Это проверка логики обработчика, не запись нативного жеста на устройстве.
