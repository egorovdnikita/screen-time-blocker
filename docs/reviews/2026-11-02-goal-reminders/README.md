# Цели по дням и напоминания —170–177

Внесены правки. DailyGoal использует общий WheelColumn:0–24ч с шагом5мин, минимум5мин,24ч только с00мин. Семь целей копируются в черновик, отмена не меняет состояние. Изменения подтверждаются галочкой, затем toast «Изменения сохранены». «Отключить цель» скрывает цель на Главной; ± в общих настройках включает её обратно и задаёт одинаковое значение всем дням. День цели выбирается по текущему дню недели устройства; для демонстрационного24июня — среда. Историческая цель применяется к соответствующему дню, исходные значения сохраняются до первого изменения.

Reminders — общий лист с независимым черновиком. До цели0–120мин и каждые0–240мин, шаг5;0=Нет. Нельзя сохранить неизменённые значения. Первое включение показывает БЕТА-предупреждение; отмена предупреждения сохраняет черновик, отмена всего листа ничего не применяет. Подтверждение сохраняет локальную настройку, повторное редактирование не требует БЕТА снова. Обнуление обоих интервалов выключает настройку.

Это прототип настройки, **уведомления ОС не запрашиваются и не планируются**. Копия предупреждения взята из исходника; реальная доставка не имитируется. Все новые данные хранятся в памяти и сбрасываются демо-сценарием.

Оболочка SettingsStack общая с каталогом/расчётным временем. Круглые действия44, строка дня50.667, группа сy190.333. Для субботы колесо y494.333/h246; используется то же WheelColumn, что в длительностях сессий и лимитов. Напоминания: лист x8/y506/bottom8, строка62, stepper88×30. БЕТА: x37/y342.645/h192, в одном уровне статическое затемнение, отдельно PopIn; системный Modal.slide не используется. SVG импортированы.

Все8состояний сопоставлены с оригиналами, в том числе колёса и предупреждение. check-goal-reminders: сохранение/отмена субботы, воскресенье, отключение/повторное включение цели, отмена БЕТА/черновика, включение/выключение напоминаний, истечение toast. Сравнения в галерее. На iPhone и Android визуально не проверено, системная клавиатура не рисуется. Счётчики/динамические значения отличаются от неизменяемых исходных снимков.
