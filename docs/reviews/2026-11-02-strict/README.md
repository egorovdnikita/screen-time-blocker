# Строгий режим — 2 ноября 2026

Обновлены095–097/100–101. Переключатель открывает StrictSettingsSheet: на время сессии или заданное число дней1–30. Отмена не включает режим и не меняет срок; активация применяет настройки. Никакой реальной системной блокировки эти настройки не выполняют.
