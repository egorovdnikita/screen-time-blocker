# Исправление модальных окон профиля

По замечанию пользователя исправлены окна из предыдущей итерации: общие настройки276, вложенные время169, каталог178, правила219, группы221, экраны блокировки229, справка285–286. Новых экранов этот пакет не добавляет.

Причины: SettingsStack рисовал непрозрачный фон с отдельной картинкой неба вместо настоящего родителя; серая копия нижнего листа была внутри перемещаемого содержимого и поднималась вместе с ним. Обе имитации удалены. SettingsStack и PlainSettingsSheet используют отдельное полупрозрачное затемнение; родитель остаётся на месте. Системная строка наследует вид родителя, её цвет больше не меняется от переключателя советов. Вложенные время/правила из профиля открываются на69pt, а из Главной/Правил сохраняют исходную глубину.

Общий SheetModal поддерживает animateClose: при нажатии на подложку/аппаратном Назад лист уезжает вниз, подложка остаётся неподвижной и гаснет; владелец удаляет окно после завершения. Клавиатура закрывается в начале. Меню выбора типа экрана перехватывает закрытие, не закрывая весь лист. Прямые старые callback сохранения отдельных форм пока могут закрывать форму без анимации — это отдельный следующий проход.

В Chrome393×852 проверены7 открытий и7 закрытий: положение/высота/transform подложки на каждом кадре, движение содержимого, его остановка, удаление окна после завершения, прозрачность подложки и отсутствие движущейся копии родителя. Проверено закрытие вложенного меню. Кадры100ms — в этой папке, полный замер checks.json. Дополнительно main-settings/block-screens/goal-reminders и прежние8 открытий sheet-motion. Typecheck/lint/web-export/iOS JS-bundle. На физическом iPhone визуально не проверено; нативная компиляция не заменяет такую проверку.

Изменение подложек намеренно отличается от прежних статических сравнений: приоритет — требование пользователя о настоящем родителе и правильных слоях.
