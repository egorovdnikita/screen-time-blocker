# Группа приложений и сайты — 2 ноября 2026

Обновлены063–069 в React Native/Expo. Вход: Начать блокировку → Прямо сейчас / По расписанию → Приложения.

## Вёрстка и поведение

- **063**: AppGroupSheet — общий нижний лист, крестик и галочка44×44pt, сегменты «Только эти / Все, кроме», категории, раскрытие социальных приложений и поиск.
- **064/065**: вложенный AppGroupOptions — три ограничения с общим круглым checkbox: контент для взрослых, покупки, установка.
- **066/067**: ввод сайта, очистка, добавление и выбор сохранённых доменов. Протокол, путь, регистр и www нормализуются; неверные адреса и дубликаты не добавляются. Отключённый сайт остаётся в списке и может быть включён повторно.
- **068**: сводка пересчитывается из выбранных приложений, категорий, сайтов и ограничений.
- **069**: AppGroupSummary — компактный стек приложений и значки дополнительных ограничений в редакторе; тот же компонент применяется в новом правиле.

Галочка подтверждает весь черновик. Крестик/системное закрытие группы отменяет приложения, режим, категории, сайты и флаги вместе. Закрытие вложенного листа возвращает к сводке, сохраняя изменения только внутри ещё не подтверждённой группы. Правило/шаблон получают независимую копию AppGroupDraft. Пустая группа отключает запуск; сайт или ограничение без приложений разрешены. «Все, кроме» с пустым исключением означает все приложения.

Компоненты: AppGroupSheet, AppGroupOptions, AppGroupCheck, AppGroupSummary; состояние — src/data/appGroup.ts и SessionDraft/SessionRule. Изображения категорий взяты из PNG выгрузок; SVG галочки, глобуса, микрофона, установки и стрелок импортированы генератором. Штрихи стрелок перенесены из SVG внутри HTML без перерисовки. Заливки, радиусы, checkbox и сегменты нативные.

## Ограничения

Визуально и функционально проверено в Chrome/React Native Web. iPhone/Expo Go, VoiceOver и положение системной клавиатуры на устройстве не проверены. Для клавиатуры добавлены KeyboardAvoidingView и компактная шапка поиска на мобильных платформах. Микрофон в поиске — исходная пиктограмма, голосовой поиск не подключён.

Каталог содержит только три приложения из макета и шесть категорий. Это не список установленных приложений iPhone: разрешение Screen Time и реальная системная блокировка по приложениям/доменам/покупкам не реализованы. Выбор пустых категорий хранится как категория; дополнительных приложений из головы не добавлено. Все данные живут в памяти до перезапуска. Полная приёмка1:1 на устройстве не заявлена; системная строка в Web не имитируется.
