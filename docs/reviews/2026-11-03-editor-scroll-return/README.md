# Возврат прокрутки и стабильный строгий режим

Исправления внесены в общие компоненты и редакторы сессии, лимита времени и рутины.

- Шапка и рекомендации остаются в одном ScrollView при раскрытии секций. Удалена подмена шапки компактной раскладкой. Раскрытая секция получает настоящую прокрутку; шапку можно вернуть обратным жестом.
- Жест из прокрученного списка возвращает контент к началу. Закрытие разрешено новым жестом от начала списка. Горизонтальные карусели не перехватывают владельца вертикальной прокрутки.
- Нативный обработчик закрытия читает актуальный запрет из NativeScrollGate, включая вызовы старого обработчика до React rerender. Регрессия воспроизводилась на предыдущем исходнике и проходит после исправления.
- Нативный Switch выровнен по центру строки без изменения системных размеров. У строгого режима удалены условная стрелка и сдвиг 26 pt. Координаты свитча до/после включения в браузере: x=310, y=699, ширина=63 pt.
- Верхний отступ нижних действий — 20 pt; нижний отступ списков — 32 pt. Общие значения применены к четырём редакторам.

## Проверено

Chrome, 393×852: раскрытие секций трёх редакторов, неизменный ScrollView, возврат шапки без закрытия, последующий свайп закрытия, зазор последнего элемента и положение свитча. Изображения и замеры находятся рядом, результаты — checks.json. Кадр strict-on-stable.png просмотрен визуально: стрелки нет.

Expo Go на физическом iPhone: через runtime измерено центрирование системного свитча. Центр первой строки y=392 pt совпадает с центром свитча. При раскрытии активности ранее наблюдался настоящий scroll offset=251 вместо 0 при старой подмене раскладки. В сохранённом позднем снимке editorScroll пуст, поскольку пользователь уже перешёл на другой экран. Файл native-measurements.json содержит измерения Switch.

Реальный свайп пальцем на iPhone после исправления самостоятельно не проверен: инструмента управления устройством нет. Браузерные жесты не заменяют эту проверку.

Дополнительно проходят typecheck, lint, проверки lifecycle/нативного Switch и сценарии создания лимита времени и рутины. Web export и JS bundle для iOS собраны локально. Исторические снимки функциональных сценариев не перезаписывались в git.
