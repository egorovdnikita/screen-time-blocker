# 190–196 · Открытие приложения

Внесены правки и добавлены 7 состояний. Общая векторная UnlockCard вместо изображения с запечённым текстом; общий SheetModal с неподвижной подложкой. Пауза отсчитывается по реальному времени, причина обязательна, разрешённые минуты ограничены настройкой. Отмена не тратит вход, подтверждение тратит один, повторное нажатие защищено. После окончания таймера кнопка снова доступна, пока не исчерпаны входы.

Проверено в Chrome 393×852: ожидание, отмена, обязательная причина, 2 минуты, запрет превышения длительности, истечение, 0/3, переходы на Главную/Профиль. Все 7 пар просмотрены визуально. Проверки: tools/check-app-unlock.mjs.

Это локальное демо: приложения ОС не открываются и не разблокируются; записи живут в памяти. Методы текста/сканирования пока не подключены. 193 — реальное поле ввода без нарисованной клавиатуры. Время и фон отличаются от исходного снимка. На iPhone визуально не проверено.
