# 276,285–286 · Общие настройки и справка

Добавлены 3 состояния. Профиль → кнопка с многоточием открывает MainSettings; из неё открываются существующие ScreenTimeSettings и RuleSettings. Вложенные окна возвращают родительское состояние. SettingsStack переиспользован с настройками радиуса/поверхности/шапки. Фон плана и синей кнопки — View/тени, не изображения. Иконки получены генератором из исходных SVG, help-contact — из sprite.svg с правильным viewBox/currentColor. Фон шапки справки чистый, без запечённых часов.

HelpFeedback показывает обе позиции прокрутки. Статьи, отправка отзыва/контакт, экстренный режим, подписка, язык/уведомления/интерфейс ещё не подключены; не имитируется покупка или отправка. Тариф/аккаунт — исходные демо-данные. В 286 верхняя граница прокручиваемого содержимого на 18.333pt выше отдельного исходного снимка: сохранена единая геометрия живого списка. Это известное расхождение, полного 1:1 не заявлять.

Все 3 пары просмотрены в Chrome393×852. Проверены пути к времени/правилам, справка/прокрутка, два уровня назад, соседняя Главная. Соседний каталог занятий повторно проверен после расширения SettingsStack. Typecheck/lint/web-export/iOS JS-bundle проверены; физический iPhone визуально не проверен.
