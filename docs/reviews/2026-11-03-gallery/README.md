# 208–209 · Галерея шаблонов

Добавлены TemplateGallery, фильтры Все/Сессии/Лимиты/Рутины, личные шаблоны и 6 готовых подборок. Заголовок/вкладки остаются на месте при прокрутке. Рабочие часы/утренний фокус/ночь/утро/вход с намерением передают настройки в SessionEditor; часовой лимит открывает TimeLimitEditor с 60 мин. Пользователь выбирает приложения/проверяет настройки перед сохранением. Неизвестный параметр не меняет обычный редактор.

SavedTemplateCard переиспользован для личных; кнопка Начать применяет сохранённый шаблон. Новая кнопка открывает редактор, где можно сохранить шаблон. У рутины нет придуманных готовых подборок; фильтр показывает только реально сохранённые.

Фотографии отделены от UI. В исходных clean.png оставались запечённые бейджи/кнопки и остатки букв: локально восстановлены через OpenCV (tools/gen-gallery-art.py), новые заливки/рамки/текст — View/SVG. Восстановление утраченной фотографии приблизительное, полного совпадения пикселей в этих зонах нет. В проект не добавлены пакеты: OpenCV только во временном окружении /tmp/block-image-tools.

Chrome393×852: просмотрены оба состояния и прокрутка; tools/check-gallery.mjs проверяет фильтр и передачу длительности/расписания в редакторы. Системная строка/личные данные/обрезка третьей карточки отличаются. iPhone/Android визуально не проверены, OS-блокировки нет, данные в памяти.

Дополнительно tools/check-gallery-presets.mjs проверяет все 5 сценариев, переход через полночь,7 дней и независимость черновиков. Вечерний текст приведён к двум строкам исходника.
