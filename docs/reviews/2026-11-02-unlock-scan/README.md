# Способы открытия и сканирование — 2 ноября 2026

Внесены правки и перенесены состояния083,090–093.094 (QR-пропуск/экспорт) не перенесён.

## Что изменено

- Один каталог `unlockMethods` для всех девяти строк: ничего, пауза, причина, текст, код, фото, пароль, сканирование, зеркало. Раньше часть строк отсутствовала. Код/фото/пароль/зеркало пока отключены; выбор не имитируется.
- QR/NFC — состояния общего `UnlockMethodSheet` и `ScanMethodSettings`. Исходные изображения телефона и emoji скопированы из выгрузки. Иконки меню импортированы генератором из исходных SVG.
- `scanType` хранится в черновике и передаётся в правило/шаблон вместе со способом. Закрытие по подложке отменяет выбор; Сохранить подтверждает QR. NFC без привязанной метки не сохраняется.
- Непрозрачная подложка листа повторяет оригинал. Убраны видимые хвосты предыдущих строк в прокрученном списке и QR-состоянии. Существующие карточки паузы/причины/текста переиспользуются.

## Проверки

`tools/check-unlock-scan.mjs`: наличие всех методов, координаты QR, выбор NFC, запрет сохранения без метки, отмена всего выбора и отдельной смены типа, сохранение QR, повторное открытие, создание/применение шаблона, отсутствие ошибок браузера. Применение шаблона проверено по созданной сессии; сохранение поля scanType в модели — по коду, не по отдельному интерфейсу редактирования шаблона.

Регрессия: check-unlock-methods, check-unlock-text, check-session-flow. Typecheck, lint, web-export и сборка iOS bundle. Пять состояний сверены глазами с HTML-снимками в Chrome393×852; пары добавлены в общую галерею. Это не полная приёмка всего проекта1:1.

## Ограничения

Это перенос настроек: реального чтения QR камерой, привязки NFC, экспорта QR-пропуска и системного ограничения Screen Time нет. Экспорт и привязка метки отключены, выбранный QR — конфигурация прототипа. Ссылка «Где найти NFC-метку?» пока информационная подпись без перехода. Веб не рисует системный status bar из исходного снимка; на iOS он системный. На реальном iPhone и с VoiceOver пакет визуально не проверен. Данные остаются в памяти.
