# 219–228 · Настройки правил и группы приложений

Внесены правки и добавлены10состояний. RuleSettings, общий PlainSettingsSheet, NamedAppGroups и AppGroupSheet purpose=named. Категории выбираются независимо от приложений, пустое сохранение заблокировано, имя редактируется с отменой и защитой от пустых/повторяющихся названий. Каталог в AppState, глубокое копирование. Заголовок выбора группы в редакторах сессии/рутины открывает каталог; применение не изменяет сохранённый оригинал. Форма выбора передаётся через renderEditor, циклических импортов нет.

Все10пар просмотрены в Chrome393×852. 224/225 — настоящее поле ввода; нарисованная iOS-клавиатура не переносилась. На физическом iPhone не проверено. Строки экранов блокировки/квот пока не подключены, старые лимиты через Shortcuts недоступны. Подсчёт категорий локальный, реального Screen Time-каталога нет. Данные в памяти; редактирование сохранённой группы не изменяет ранее созданные правила.

useStatusBar использует отдельные записи стека RN на время фокуса: модальные окна корректно возвращают предыдущую запись, прокрутка не перезаписывает верхнюю. Web не вызывает отсутствующие stack API. Проверка check-status-bar проверяет вложенный override/восстановление/очистку; физическая визуальная проверка не заявлена.
