# Рутина — 2 ноября 2026

Перенесены131–139.140/141 обновлены в части новой карточки рутины в существующих данных «Правил», без копирования всей исходной страницы.

## Что работает

- Меню «Выполнить привычки» открывает маршрут `/routine`. В результате все пять пунктов меню имеют рабочие редакторы прототипа.
- Заголовок редактируется. Общие RuleEditorHeader и RuleSuggestions используются также лимитом времени. Подборки показаны по исходнику, их содержимое не выдумано: применение подборок пока отключено.
- «Связать группу» — вариант общего AppGroupSheet с пустой начальной группой, режимами Только эти/Все кроме, категориями, приложениями и дополнительными ограничениями/сайтами. Сохранение подтверждает черновик, закрытие отменяет. Исходные132/133 показывают вариант с одной категорией; её выбор не разворачивается в три отдельных приложения.
- «После»: Накопить время / Выполнение. Общая библиотека содержит четыре показанные фото-привычки; можно выбрать несколько, искать без учёта регистра и отменять выбор. Чистка комнаты сохраняется с названием «Убрать комнату», как в138. Стартовое значение награды —5минут, для других показанных фото-привычек применяется тот же локальный дефолт; отдельные настройки награды в этой серии не показаны.
- «Активно»: системный Switch «Весь день» и общий WeekdayPicker. Минимум один выбранный день; сохраняется набор дней и значение Switch. Детальная настройка часов при выключенном «Весь день» в данном пакете не перенесена.
- Настройки строгого режима и подтверждение переиспользованы. Сохранение рутины/шаблона запрещено без группы и привычки. createdRoutines/savedRoutineTemplates в AppState; счётчик активных и карточки обновляются. Применение шаблона создаёт отдельную запись. После добавления — прокрутка к новой рутине; после сохранения шаблона — к шаблонам. Reset демо-сценария очищает новые записи.

## Общие исправления

- SessionAction: неактивная основная кнопка #b3b4b8 с текстом #cdced2; вторичная #a9aaae с opacity.65. В активной основной кнопке LinearGradient исходных цветов, радиус32. Применено через общий компонент, не отдельными копиями.
- В четырёх прозрачных редакторах используется существующий useDarkStatusBar. Над светлой подложкой системные иконки тёмные; при возврате Главная восстанавливает свой стиль. Рисованного status bar нет.
- SVG эмблемы из habit-picker импортирован в Icon. Генератор теперь удаляет размеры только у корневого SVG и сохраняет width/height вложенных фигур. `tools/check-icon-generator.mjs` проверяет это в изолированной временной папке на rect/image; рабочий реестр тестом не меняется.

## Проверки

`tools/check-routine.mjs`: запрет пустого сохранения, отмена/подтверждение группы и привычки, поиск, смена режима, дни и Switch, создание правила, недоступность имитации ИИ, создание/применение шаблона, счётчик. Координаты заголовка дней записаны в checks.json. Ошибок браузера нет.

Регрессия: check-time-limit, check-app-group, check-session-flow; typecheck/lint/web-export/iOS bundle.11состояний сопоставлены с оригиналами в Chrome, крупные пары и контактные листы сохранены рядом. Общая галерея обновлена. На реальном iPhone, с клавиатурой и VoiceOver визуально не проверено.

## Что не подключено

Это локальный прототип: нет FamilyControls/Screen Time, распознавания фотографий, отправки фото, начисления реального времени и постоянного хранения. ИИ-проверка новой карточки отключена; успешная проверка не имитируется. Строка «Полезное приложение», создание/редактирование новых привычек, применение рекомендованных подборок и изменение начального кредита «Начать с:0с» пока не подключены. У HabitPicker поиск фильтрует существующий каталог.

140/141 используют реальные соседние демо-данные приложения и общий компонент уведомления. Их общий состав, счётчики, расположение страницы и некоторые стили отличаются от полного исходного кадра; полная приёмка1:1 не заявлена.
