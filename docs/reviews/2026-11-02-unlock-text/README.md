# Перепечатать текст — 2 ноября 2026

Обновлены086/087/089 в общем UnlockMethodSheet. Способ доступен через Пауза → Указать причину → Перепечатать текст. Карточка автоматически прокручивается к выбранному способу, как в исходном кадре086. Поле многострочное, до2000символов; пустой текст блокирует сохранение. «Идея текста» переключает две локальные заготовки из HTML, без облака.

Текст и способ применяются только кнопкой «Сохранить». Отмена не меняет SessionDraft. Настройки передаются в SessionRule и шаблон. Сокращённые подписи методов в редакторе исправлены на «Указать причину» и «Перепечатать…» из оригиналов085/087. Иллюстрация телефона — оригинальный PNG; текст поверх неё — T. Статическая цитата внутри миниатюры сохранена из макета и не является полем пользователя.

Проверки: typecheck, lint, web-export; check-unlock-text.mjs и регрессия check-unlock-methods.mjs. Сценарий проверяет заготовку, смену идеи, запрет пустого текста, отмену, повторное открытие с сохранённым текстом, обрезку пробелов и применение шаблона. Ошибок браузера нет. Координаты поля проверяются автоматически: x36/y467/w321/h100 на393×852.

Визуально проверено в Chrome. iPhone и системная клавиатура пока не проверены; добавлен KeyboardAvoidingView. Анимационный промежуточный кадр088 отдельно не воспроизводился и не считается перенесённым. Сравнения086/087/089 — comparison-*.png, оригинал слева. Подложка остаётся текущей Главной, системная строка не имитируется в Web. Реального экрана перепечатывания при разблокировке приложения пока нет; это настройки прототипа.
