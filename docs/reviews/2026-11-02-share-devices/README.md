# Общий доступ Screen Time —129

Перенесена инструкция полным маршрутом /share-devices. После первого создания обычного лимита открывается инструкция; крестик и «Готово» возвращают к созданному правилу. Шаблоны не запускают инструкцию, повторное создание после просмотра её пропускает. Флаг хранится в памяти и сбрасывается демо-сценарием.

Системные настройки iOS не меняются: переключатель — неинтерактивная иллюстрация общего FlowSwitch, исключённая из навигации VoiceOver. На iOS используется системный UISwitch без размеров/масштабирования; в веб-иллюстрации44×28 бегунок24. Стандартные интерактивные Switch не изменились, их native-анимация сохранена.

Заливка и иллюстрация компонентами, кнопка общим DarkButtonSurface, фон векторным LinearGradient. Координаты title157, copy230, панель379/h115, шаги522, кнопка снизу39/h60. SVG закрытия из оригинала. Сверено в Chrome393×852, сравнение рядом; на физическом iPhone/Android не проверено. Реального Screen Time нет.

check-time-limit дополнен проходом инструкции и повторно проверяет весь поток создания лимита/шаблона. Старые128/130 остаются частично обновлёнными страницами с текущими демо-данными, а не полными копиями всего кадра.
