# Нативный стек iOS и свайп по содержимому

По уточнению пользователя верхние карточки должны складываться как системные экраны, а закрытие не должно требовать попадания в ручку.

На iOS полноразмерные SettingsStack/PlainSettingsSheet и9прямых листов используют RN Modal transparent=false/presentationStyle=pageSheet/animationType=slide/allowSwipeDismissal. Убраны JS-затемнение и JS-перемещение этой ветки; UIKit отвечает за настоящий родительский экран и интерактивное закрытие. Старый viewport-отступ компенсирован отрицательным верхом внутреннего контейнера, поэтому нет двойного пустого зазора. Родительский gesture-context изолирован. После программного закрытия callback ждёт native onDismiss; нативный swipe приходит через onRequestClose после завершения UIKit. Повторное событие защищено. При локальном меню swipe запрещён. Проверено по RN0.88Modal API и локальному Fabric-коду, а не по предположению о реализации Т-Банка.

Веб/Android и короткие нестандартные листы остаются на общей JS-презентации. Теперь вертикальный жест по содержимому может закрыть лист: захват после6pt с преобладанием вертикали; закрытие после72pt или быстрой тяги; короткий жест возвращается. Отслеживается активный вложенный ScrollView, прокрученный список отдаёт жест прокрутке. WheelColumn блокирует захват листом через responder capture. Приоритет получает только верхний sheet; центрированные диалоги не перетаскиваются.

Проверены touch-жесты по содержимому напоминаний/настроек времени, незакрытие прокрученной справки, независимый жест барабана и последующее закрытие через ручку. Дополнительно12touch-сценариев в соседнем отчёте и11закрытий кнопками profile-form-dismiss. Typecheck/lint/web-export/iOS JSbundle и modal-lifecycle проходят. Lifecycle-тест выполняет iOS-ветку: непрозрачный pageSheet, разрешение свайпа, callback после onDismiss, once-only cancel, Android/Web fallback. Нативную геометрию/анимацию на физическом iPhone не проверяли; браузер не показывает UIKit-стек. Короткие листы ещё не переведены на нативные detents; корневые редакторы маршрутов сохраняют прежнюю JS-презентацию. Не утверждать, что весь стек приложения уже нативный.

API: https://reactnative.dev/docs/modal и https://docs.expo.dev/router/advanced/stack/ . Новых зависимостей/нативной сборки не требуется, используется модуль RN из Expo Go.
