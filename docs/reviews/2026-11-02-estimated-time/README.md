# Расчётное время —182–185

Внесены UI-правки: общий SettingsStack, раскрываемое пояснение с исходными выделениями, история, фактическое/расчётное время, действие обновления, уведомление и вариант с галочкой точности. Раскрытие не меняет числа. Фактическое время берётся из текущего демо-дня12мин вместо скачков0с/23мин в исходных кадрах.

**Расчёт демонстрационный:** refreshEstimatedDemo переключает исходные состояния125→110→125мин и пометку точности. Это не обращение к Screen Time и не реальное улучшение системного учёта. Значение сохраняется в памяти и используется также родительской строкой настроек; после перезапуска сбрасывается. Toast повторяет оригинал и исчезает через4секунды. «Повысить точность» и «Руководство» не активны: связанных инструкций/интеграции в пакете нет. Дни истории показаны по макету и не выдают вымышленные данные по нажатию.

Календарь/поля/статусы/градиенты — элементы RN, не снимок интерфейса. Оболочка использует чистую текстуру неба без вшитого status bar. Общий DarkButtonSurface даёт векторный градиент/ободок/тень всем тёмным действиям настроек, инструкции и редакторов.

Все4кадра сопоставлены в Chrome393×852, крупные пары рядом. Раскрытый текст/расстояния проверены; кнопка y509.667/h41. check-estimated-time: раскрытие/сворачивание, демонстрационное обновление, сохранение между открываниями, истечение toast. Нативная iOS-сборка компилируется; на iPhone/Android визуально не проверено. Полное совпадение динамических данных с каждым исходным кадром не заявлено.
