# Связь оценок со сводкой

После сохранения оценки список «Активности» и проценты качества рассчитываются по локальным записям выбранного дня. Одинаковое занятие с одинаковой оценкой объединяет время и иконки приложений; разные оценки остаются отдельными строками. Исключение и удаление убирают вклад записи. Длительности и отношения полос берутся из показанных приложений.

Первые пользовательские изменения переключают сводку дня с несвязанных демонстрационных активностей на реальные локальные записи. Поэтому старые демонстрационные строки не дублируются с новыми. После удаления всех записей остаётся пустая сводка; демо-строки не восстанавливаются. Новый демо-сценарий сбрасывает записи и возвращает исходные макетные данные.

В исходниках счётчики противоречат списку: на Главной12мин, а приложения суммарно44мин. Для локального расчёта качества знаменатель — максимум исходного итога и суммы известных приложений за вычетом исключённых. Неотмеченное время нейтральное, округление сохраняет100%. В карточке качества отображается используемый итог; основной исходный счётчик не подменяется. Это ограничение демонстрационных данных, а не реальные измерения Screen Time.

Почасовой график не пересчитан: в HTML нет распределения длительности каждого приложения по часам. Подбор/выдумывание часовых интервалов не выполнялись. Предпочтение «Всегда» не классифицирует несуществующие события ОС.
