# Лимит запусков — 2 ноября 2026

Перенесены состояния103–106,108–111;112/113 обновлены в части добавления новой блокировки в существующую страницу «Правила». Пункт «Лимит запусков» меню102 теперь открывает редактор.107 (промежуточная настройка со спиннером) не воспроизводится: работа с локальным каталогом синхронна.

## Поведение

- Маршрут `/lock`: исходно3запуска по5минут, без приложения. Добавление недоступно до подтверждения приложения. Счётчик1–99, длительность1–120минут; сумма пересчитывается из этих значений.
- SingleAppPicker: десять категорий из оригинала, раскрытие «Социальных сетей» с4демо-приложениями, поиск без учёта регистра, выбор одного приложения. Пустые категории не заполняются вымышленными приложениями.
- Второй шаг: подтверждение названия/иконки, популярные приложения, поиск и рекомендации из исходного кадра. Выбор подтверждается кнопкой «Это…». Назад возвращает к первому шагу; закрытие всего листа отменяет черновик. При повторном открытии исходное выбранное приложение сохраняется, но не подтверждается автоматически.
- Длительность и способ открытия переиспользуют UnlockDuration/UnlockMethodSheet. Общий StrictModeRow вынесен из SessionEditor, используется в обоих редакторах; системный Switch на iOS сохранён.
- Правило передаёт приложение, число запусков, длительность, способ открытия и настройки строгого режима в createdLocks. Страница «Правила» показывает новую карточку и уведомление; таббар/заголовок учитывают новую блокировку. Карточки блокировок теперь прокручиваются горизонтально. Пункт «Добавить» в этом ряду открывает тот же редактор.
- SheetTransition/SheetModal сохраняют неподвижное затемнение. Системная анимация прозрачного маршрута отключена, как у редактора сессии.

## Проверки

`tools/check-lock-rule.mjs`: запрет пустого добавления, отмена выбора и настроек, поиск/подтверждение, граница счётчика1, изменение длительности и суммы, строгий режим/срок/отмена подтверждения, добавление карточки/уведомления/счётчика, повторный вход из «Правил». Координата строки приложения проверяется автоматически. Typecheck, lint, web-export и iOS bundle; регрессия check-session-flow/check-strict-flow после выделения общего StrictModeRow.

Десять состояний сопоставлены с HTML-снимками, пары добавлены в галерею.112/113 показывают фактические демо-данные текущего приложения: соседние сессии, общий счётчик и расположение заголовка не являются копией всей страницы оригинала. Полная приёмка этих двух страниц1:1 не заявлена. Веб не имитирует status bar iOS. На физическом iPhone/с экранной клавиатурой пакет визуально не проверен.

## Ограничения и продолжение

Локальный каталог содержит15названий из референсов, не список установленных приложений. Реального FamilyControls/Screen Time, системного подсчёта запусков, открытия блокированных приложений и постоянного хранения нет. «Дни и другие приложения» пока информационная отключённая строка; список её настроек не показан в данном исходном наборе. Настройки строгого режима сохраняются как конфигурация прототипа, системные запреты не включаются. Раскрытого списка «Запретить…» в доступных оригиналах нет, его содержимое не придумано.

Следующие крупные потоки меню: «Лимит времени» и «Выполнить привычки». Экспорт QR094 и остальные способы открытия также остаются в очереди.
