# Разблокировки и шаблоны — 2 ноября 2026

Пакет продолжает React Native/Expo. Макеты берутся из локального ../block/dist, HTML не встраивается в приложение.

## Изменения

- **054**: свёрнутое расписание, дни в краткой строке и подзаголовке, «Подборки», обложки и подписи расписаний.
- **055**: секция «Разблокировки» → «Да/Нет», короткая шапка197pt, компактная молния из оригинала.
- **056**: развёрнутая секция374pt, счётчик, длительность входа, максимальное общее время. Один компонент SessionUnlocks также используется для немедленной сессии.
- **057/058**: карточка сохранённого шаблона с расписанием, описанием и действием «Добавить»; следующая карточка «Глубокий фокус» использует оригинальную обложку. Шаблоны автоматически показываются после создания. Это обновление секции существующих Правил, а не отдельная копия всего экрана.
- **076/077**: настоящий bottom sheet длительности разблокировки с общим WheelColumn. Отмена не меняет черновик; подтверждение применяет1–120мин. Верхняя граница фиксирует2ч00мин.
- **050/051**: циклические минуты00↔59, видны58/59 над00. Исправлен порядок приложений в общем стеке редактора.

## Проверки

Typecheck, lint, web-export и три браузерных сценария: tools/check-session-unlocks.mjs, tools/check-session-pickers.mjs, tools/check-session-flow.mjs. Ошибок браузера нет.

Новый сценарий проверяет переходы59↔00 в обе стороны; минимум счётчика1; отмену выбора времени; предел2ч; невозможность нулевой длительности; пересчёт максимума30→20мин; восстановление настроек после «Нет/Да»; сохранение и применение шаблона09:00–18:00 с2разблокировками.

Измерено в393×852: приложенияy150/h59; активностьy223/h59; развёрнутый заголовок разблокировокy292/h54; тело320pt; кнопки счётчика41×41; лист длительностиy390 до844; нижние действияy753/h60. См. checks.json.

Снимки054–056 и076–077 сопоставлены с оригиналами слева в comparison-*.png. Также просмотрены новые снимки поповера и шаблонов. На iPhone/Expo Go не проверено.

## Что не завершено

Содержимое Правил над шаблонами определяется текущими данными: в исходном057/058 одна активная сессия, в обычном сценарии приложения есть и другие правила. Положение шапки/системной строки в Web отличается от физического iPhone. Полное совпадение1:1 не заявлено. Пункты «Пауза» и «Без задержки» пока показаны как параметры оригинала без настроек; их отдельные экраны идут следующим пакетом. «Всегда» и три оставшихся потока меню блокировки пока отключены. Все созданные правила и шаблоны живут в памяти, реальной блокировки нет.
