# Раздельная анимация листа и затемнения

Исправление по замечанию: при открытии снизу поднималась и полноэкранная подложка.

Причины: `Modal animationType="slide"` переводил всё нативное окно, включая затемнение; маршрут session использовал `slide_from_bottom` с таким же результатом.

`SheetModal` теперь открывает прозрачное нативное окно без системного slide. Общий `SheetTransition` содержит два соседних слоя: неподвижный fullscreen backdrop (только opacity) и содержимое листа (только translateY). Анимация320мс, easeOut cubic, native driver на iOS/Android; старт после Modal.onShow. Маршрут session использует ту же композицию, его системная анимация и жест перемещения всего прозрачного маршрута отключены.

Обновлены8открытий: меню блокировки045, редактор047, иконки059/060, строгий режим095/100, длительность076/077, способы080–093, группа063/068 и вложенные параметры064–067. Всплывающие меню Главной уже разделяли затемнение/контент; центрированное подтверждение и поповер времени сохраняют fade.

`tools/check-sheet-motion.mjs` снимает кадры8открытий: во время движения листа подложка остаётся x0/y0/h852 без transform, меняется opacity; после открытия translateY0/opacity1. Проверено закрытие по подложке и возврат из вложенного листа. В папке сохранены промежуточные PNG и проверки кадров в checks.json. Промежуточные снимки просмотрены глазами в Chrome. Это не проверка анимации на физическом iPhone; там проверены только код и сборка iOS bundle.

Закрытие условно смонтированных листов пока мгновенное. Новая анимация относится к открытию; отдельный выход/свайп листа не добавлен. Нативный driver не двигает подложку, поскольку у её Animated.View вообще нет translateY.
