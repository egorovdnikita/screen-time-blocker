# 197–199 · Детали и пауза сессии

Внесены правки и добавлены 3 состояния. Общий RuleDetails для сессии/лимита, переименование с отменой и сохранением, общий строгий режим, меню приостановки и возобновление. Счётчик активных правил учитывает паузу. Строгий режим закрывает изменение активного правила.

Все 3 пары просмотрены в Chrome 393×852, меню сверено в увеличении. tools/check-session-details.mjs проверяет оба вида паузы, возобновление, отмену/сохранение имени и строгий режим. tools/check-rule-count.mjs проверяет счётчики созданных/исходных правил.

Пауза следующего запуска хранит только локальный режим: реального планировщика и автоматического возобновления нет. Срок строгого режима не контролируется ОС. Строки приложений/расписания/входов и удаление пока только отображаются. 199 — реализовано уведомление/карточка паузы, остальная страница содержит текущие данные. На iPhone визуально не проверено.
