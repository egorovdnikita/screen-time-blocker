# Дополнительные вложенные листы: touch-свайпы

12сценариев в Chrome393×852, реальные CDP touchStart/touchMove/touchEnd: иконки, строгий режим, длительность, способ открытия, параметры группы/группа, приложения лимита/запусков, новая привычка/библиотека, меню Блокировать, оценка времени. Проверены следование пальцу, неподвижный нижний лист и затемнение, снятие ровно1окна. Кнопки сохранения не нажимаются, черновики не применяются.

Добавлены свайпы меню Блокировать и оценки времени. Меню сохраняет прежний поток и высоту ручки; у оценки добавлена невидимая зона верхнего края без нового визуального элемента. В HabitForm ручка вынесена из прокрутки; при высоте600pt проверено, что содержимое прокручивается, а ручка остаётся на месте. Новых экранов0. Эти кадры — веб-ветка, не доказательство внешнего вида нативного pageSheet на iPhone.
