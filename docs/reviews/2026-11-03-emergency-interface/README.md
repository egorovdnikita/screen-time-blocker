## Где открыть

- Профиль → Настройки профиля → Помощь и отзывы → Экстренный режим.
- Шестерёнка → Код-пароль → перепечатать случайный код → создать и подтвердить свой PIN. После этого «Продолжить» проверяет выбранный PIN и открывает строгие правила.
- Для заполненного списка: долгое нажатие на «Ещё» на Главной → «Строгое правило Apple Music». Этот демо-вариант меняет только исходные правила; не создаёт пароль и не обходит проверку кода.
- Профиль → Настройки профиля → Интерфейс. Доступны показ серии, спецсимволы с предупреждением и переход в существующий редактор экранов блокировки.

## Компоненты и поведение

PasscodeScreen и CopyCodeScreen переиспользуются для проверки/создания/подтверждения PIN и перепечатывания. Закрытие и переход к следующему окну идут через SheetModal.close(afterClose), с сохранением родителя и неподвижным затемнением. Полноразмерные листы используют существующий iOS pageSheet; короткое меню действий — общий анимированный JS-лист. Нативный Switch сохранён без масштабирования.

Настройки хранятся в AppState. Отмена длины кода и предупреждения не применяет изменения. Неверный PIN не открывает правила; несовпадающее подтверждение сбрасывает цифры. Отключение strict сохраняется в ruleChanges; удаление убирает правило из списка и корректирует общий счётчик в Правилах и таббаре. Скрытие серии применяется через общий Streak с сохранением высоты шапки. Спецсимволы меняют алфавит генератора случайных кодов.

SVG импортированы из HTML через gen-icons.mjs: backspace, emergency-settings, interface-theme/app/flame. Маскот скопирован из отдельного исходного PNG. Фоны, градиенты, кнопки и поля выполнены компонентами, а не картинками экранов.

## Ограничения

Это локальный прототип Expo Go. PIN и правила живут только в памяти и сбрасываются при перезапуске/сбросе сценария. Реального защищённого хранилища, системной блокировки Screen Time и криптографической авторизации нет. Случайный код отличается от статического примера HTML.

На физическом iPhone эти18состояний не проверены. Веб не рисует поддельную iOS-клавиатуру/статус-бар:294отличается отсутствием системной клавиатуры, её должен показывать iOS. Реальное небо/родитель сохраняется вместо серой заглушки HTML — это ранее согласованное поведение модалок. Нативный Switch использует системную геометрию и материал. Тема и смена иконки приложения пока readonly;310–312не заявлены готовыми. Далее: раннийонбординг000–025 и оставшиеся системные/интерфейсные состояния.
