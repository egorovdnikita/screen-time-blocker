# Аудит и правки токенов — 2026-11-27

Область: все исходники оформления screen-time-blocker, без иконок и встроенных иллюстраций. Источник — актуальный локальный Box UI; исходники Box UI не менялись. Это отдельная полная проверка дизайн-токенов по запросу, не повторный аудит продуктовой логики. База приложения: `b4910ef`.

## Найдено и исправлено

1. Отсутствовала связь локальных копий токенов с Box UI и воспроизводимая проверка дрейфа. Добавлены снимок исходного графа, генератор React Native-значений, проверка актуального источника и автономная проверка в существующем `npm test` / CI.
2. Ахроматические цвета повторялись в наборах тем. Белый и чёрный с сохранением значения связаны с `sys-color`; белая карточка — с семантическим `surface/base/fill/raised` в Light.
3. В стилях дублировались существующие примитивы spacing, размеров, радиусов и типографических метрик. Они заменены обращениями к соответствующим шкалам без округления и без присвоения произвольных семантических размеров.
4. Цвета градиентов и составные тени обходили `tokens.ts`: Главная, график, оверлеи, нижний хром, Правила, Профиль, решение проблем, тень текста. 14 локальных материалов собраны в `localMaterials`; значения сохранены буквально. Цвет самой иконки strict-badge исключён из миграции по ТЗ.
5. Добавлены реестр оставшихся литералов и обращений к токенам и защита равенства исходных выражений. Неверных импортов и неразрешимых ссылок не оставлено; результат проверяется TypeScript и генератором.

## Оставленные конфликты

| Область | Сейчас | Box UI | Решение |
| --- | --- | --- | --- |
| Фон страницы | `colors.bg=#f4f6f8`, `bgPage=#f6f8fa` | `surface/base/fill/page`, Light = `#f5f5f5` | Сохранить локальные значения |
| Основной текст | `colors.text=#000000`, `templateInk=#111111` | `surface/base/content/strong`, Light = `#171717` | Чёрный остаётся примитивом, не ложной семантической ссылкой |
| Акцент | `bar=#3983f0`, разные локальные blue по экранам | Deep/Light `accent/fill/solid=#6366f1` | Не перекрашивать; не подбирать ближайший blue |
| Шрифт | iOS SF Pro Rounded/System, web ui-rounded/Block Text, Android системный | Inter / Inter Display / Inter Tight / Inter Variable | Сохранить семьи, веса и fallback платформ |
| Скругления | карточка 31, правило/плитка 26, иллюстрация 25, pill 999 | примитивы 24/28/32, full 9999; brand/m = 12/16/20 (Low/Medium/High) | Не округлять и не менять pill на 9999 |
| Кегль/треккинг | default 15 и 0.3, TRACK_SMALL 0.6 | font-size 14/16; другая шкала letter-spacing | Сохранить локальные метрики |
| Прозрачности/материалы | dim 20%/60%, glass и многослойные тени из HTML | стандартный overlay Light black 48%, Dark 80%; alpha-ступени 8/16/24/32/48/64/80/88 | Не заменять материал близким значением |
| Темы и моды | существующий светлый интерфейс | Light/Dark, акценты, appearance/state/status, responsive, brand radius/type | Граф сохранён полностью; продуктовые переключатели не добавлены |

Каждое оставшееся локальное значение с местом использования записано в `token-inventory.json`. Дубли локальных цветов по независимым ролям сохранены: равный hex не доказывает одинаковую семантику. Без аналога: составные тени, blur, физические hairline/обводки, координаты графиков и графики, анимации, макетные размеры и интервалы вне шкал. Они зафиксированы как исключения, не объявлены синхронизированными с Box UI.

## Механизм и приёмка

Инструкция: [TOKEN_SYNC.md](../TOKEN_SYNC.md). Генератор использует официальный парсер локального Box UI, не меняет источник и не запускает его сборку. Для CI достаточно снимка, Node 24 и уже существующих зависимостей проекта.

Проверено: typecheck, lint без предупреждений, format:check, npm test (21/21), актуальность снимка относительно Box UI, web export и iOS Hermes export. 145 исходных файлов совпадают с базой после раскрытия новых ссылок; негативная проверка generated-файла обнаруживает дрейф. В итоговом реестре 3903 локальных литерала и 5580 обращений (включая промежуточные обращения к объектам); это не число уникальных токенов и не число просмотренных экранов.

Глазами: экран знакомства 000 в уже открытом Chrome пользователя, в desktop и эмуляции iPhone 393×852. Состояние 001 дополнительно подтверждено accessibility-деревом, без отдельной визуальной приёмки. Остальные 266 состояний не просмотрены. Браузерный host CUA недоступен; нативное управление Chrome сработало, но затем активную вкладку меняла параллельная задача. Проверка прекращена без повторения таймаутов, без Playwright/Orca и без отдельного окна/профиля. Поэтому визуальное отсутствие регрессий на всех экранах не подтверждено.

iPhone/Android физически не подключались; установки на устройство не было. Expo Go поднят с очищенным кэшем на порту 8119, iOS-манифест SDK 58 отвечает; свежий dev-бандл iOS получен с HTTP 200 (8 380 912 байт). Текущая web-сборка без кеширования доступна на `http://localhost:8118`. Наличие сохранённых конфликтов означает, что полной идентичности дизайну Box UI нет и она не заявляется: приоритет — сохранить внешний вид этого приложения.
