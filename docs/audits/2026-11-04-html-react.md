# Аудит вёрстки: все 267 состояний, HTML ↔ React

Дата: 2026-11-04. Коммит: `3fd6052` (`main`). Только аудит, код не менялся.

Статус: правки внесены. Что оставлено и почему — `docs/AUDIT_LOG.md`, раздел «Сознательно не трогаем». Ниже — исходные находки. Пункт «Цвет основного текста» уточнён при правках: `#111` только на перечисленных экранах, на остальных заголовки в макете чёрные.

Охват: 267 из 267 состояний переснято на этом коммите. 25 состояний знакомства сверены подробно (замеры и снимки), остальные 242 — по снимкам: пара «эталон и React» на листах и разница пикселей. Числовые замеры DOM для 242 не снимались.

## Как сверялось

- Эталон — `screen@3x.png` из каждой папки `../block/dist/<экран>/`, уменьшенный до 393×852, и computed styles этих HTML (тексты, рамки, фоны, тени). Сами HTML-файлы показывают не всё: в папках выгрузки нет `assets/icons/sprite.svg`, поэтому звёзды, венки и стрелка «назад» в них не рисуются. Иконки сверены по PNG.
- Исходники `../block/screens/<поток>/<экран>.html?solo`, открытые по HTTP из корня `../block`, дают те же замеры, что и `dist`: все тексты и блоки совпадают на всех 25 экранах. Картинка отличается от `dist` не больше чем на 0.33% пикселей — это иконки из спрайта, которые в `dist` не подгружаются. Значит, `dist` — точная выгрузка `screens`, и находки ниже верны для обоих источников.
- React — веб-сборка Metro 8082, `/onboarding?step=N`, Chrome 393×852. Проверено 25 состояний из 25 (номера 016 в выгрузке нет).
- На iPhone не проверено. Клавиатура и статус-бар в Chrome отсутствуют (раздел «Сознательно не трогаем» в `AUDIT_LOG.md`).
- Разница сглаживания текста между iPhone-PNG и Chrome (≤1 pt) находкой не считается.

# Часть 1. Знакомство 000–025

## Общие расхождения (затрагивают много экранов)

1. **Цвет основного текста.** В HTML `#111111`, в React `#000000`. Это заголовки, строки ответов, карточки отзывов и кнопка «Продолжить» в 017. Причина — у `T` по умолчанию цвет `colors.text = #000`, а `onboardingTheme.ink = #111` в знакомстве не передаётся. Экраны: 001, 002, 003, 008, 015, 017, 019–025.
2. **Тень тёмной кнопки внизу экрана.** В HTML у `.audit-dark-button` внутренний ободок `inset 0 0 0 .833px #929393` плюс внешняя тень `0 6px 16px #1018200a`. В React видно только ободок: у `OnboardingButton` стоит `overflow: hidden`, и он обрезает внешнюю тень `DarkButtonSurface`. Экраны: 000–003, 008–015, 017, 021–025.
3. **Выключенная кнопка.** Текст «Продолжить»: в HTML `#ededed` (004) и `#d0d0d4` (019, 020), в React `#ffffff`. Фон: в HTML `#bcbcbc` (004) и `#b5b5bb` (019, 020), в React `#b7b7b9` везде.
4. **Серые подписи** — свой цвет в каждом месте, в React один `muted #9299a4`:
   - 007 «В среднем за день»: `#a0a0a0`;
   - 021 счётчик «3»: `#aaaaaa`;
   - 022/023 «На» и «за разблокировку»: `#c5c9ce`;
   - 024 «Время подумать»: `#929292`;
   - 025 «Пропустить»: `#c7cbd0`;
   - 025 подписи строк «Блокировать / Активно / Разблокировки»: `#818a98`.
